Klangwerk Dashboard · klangwerk.kompassapps.de · Stand: 22.11.2026

Worum es geht

Das Klangwerk Dashboard ist ein privates Projekt von Tekin Bayazit. Es zeigt Statistiken der eigenen YouTube-Kanäle (Klangwerk Music, Klangwerk Kids, Kompass Schule) auf einer Webseite an.

Welche Daten verwendet werden

Mit Erlaubnis des Kanalinhabers werden über die offizielle YouTube-Schnittstelle (YouTube Analytics API und YouTube Data API) nur zusammengefasste Kanalstatistiken gelesen, zum Beispiel Aufrufe, Wiedergabezeit, Abonnentenzahl, Zugriffsquellen und Videotitel.

Es werden keine personenbezogenen Daten von Zuschauern gelesen oder gespeichert. Der Zugriff ist nur lesend: Es wird nichts hochgeladen, geändert oder gelöscht.

Wo die Daten liegen

Die zusammengefassten Zahlen werden einmal täglich abgerufen und als Datei auf dieser Webseite (GitHub Pages) gespeichert. Die Zugangsschlüssel liegen geschützt als Geheimnisse bei GitHub und sind nicht öffentlich.

Besucher dieser Webseite

Diese Webseite setzt keine Cookies, nutzt keine Analyse- oder Werbedienste und speichert keine Daten ihrer Besucher. Der Anbieter GitHub kann technisch notwendige Server-Protokolle führen; siehe die Datenschutzerklärung von GitHub.

Weitergabe

Die Daten werden nicht verkauft und nicht an Dritte weitergegeben. Die Nutzung der Google-APIs richtet sich nach den Google API Services User Data Policy.

Zugriff widerrufen

Der Kanalinhaber kann den Zugriff jederzeit in seinem Google-Konto unter myaccount.google.com/permissions entziehen.
